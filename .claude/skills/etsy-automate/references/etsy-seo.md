# Etsy SEO — Règles générales 2025-2026

Sources : Etsy Seller Handbook (août 2025), eRank, Marmalead, RankHero, recherche de terrain juillet 2026. Applicable à toute niche.

---

## 1. Algorithme Etsy — comment ça marche

Deux étapes distinctes. Les confondre est l'erreur la plus répandue.

**Étape 1 — Query matching (accès au pool)**
Etsy scanne dans cet ordre de priorité : title → attributes → categories → tags → description.
Si le mot-clé de l'acheteur ne matche rien → listing absent des résultats, peu importe le reste.

**Étape 2 — Ranking (position dans le pool)**
Context Specific Ranking (CSR) : Etsy personnalise l'ordre pour chaque acheteur selon son historique de navigation et d'achat. Pas de "rang #1" universel.

Facteurs de ranking par ordre de poids (estimations multi-sources, pas officiellement pondérés) :
1. Listing Quality Score : clics, favoris, ajouts panier, achats. Le signal le plus fort.
2. Shop Experience Score : note vendeur, taux de réponse messages, livraisons dans les délais, taux litiges.
3. Frais de livraison : livraison gratuite = boost. Livraison US > 6$ = malus de visibilité (en vigueur depuis octobre 2024).
4. Recency : un nouveau listing reçoit un petit boost temporaire (quelques jours à 2 semaines max). Utilise-le en publiant un listing déjà 100% optimisé.
5. Star Seller : pas d'effet direct sur le rang. Effet indirect via meilleure note → meilleur Shop Score → meilleur ranking.

**Ce que ça implique :**
- Un mauvais titre bloque au stade 1. Tu n'entres même pas dans le pool.
- Un bon titre mais une mauvaise photo = tu entres dans le pool mais personne ne clique = Listing Quality Score bas = tu es rétrogradé.
- Les photos et le prix impactent le SEO indirectement via la conversion.

## 2. Titre — règles applicables à tout produit

### Contraintes techniques
- 140 caractères maximum (indexés en totalité par Etsy).
- Affichage mobile : ~40-50 chars avant coupure (46% du trafic Etsy vient de l'app mobile, Q3 2025).
- Affichage desktop : ~55-70 chars.

### Règles de construction (officiel Etsy août 2025 + eRank 2025)

**Règle 1 — Mot-clé primaire en premier**
Les 40 premiers caractères sont les seuls que la majorité des acheteurs voient. Le mot-clé le plus important du produit va là. Pas un adjectif. Pas un nom de boutique. Le nom du produit.

Exemple : `Bath Towel Set, 3 Piece Cotton` bat `Beautiful Luxurious Towels for Your Daily Spa Ritual`

**Règle 2 — Long-tail (3+ mots) plutôt que termes génériques**
"Personalized ceramic mug" > "mug". Les acheteurs long-tail ont une intention d'achat plus forte et un taux de conversion meilleur. Un seul terme générique dans le titre = concurrence maximale, conversion faible.

**Règle 3 — Langage naturel**
Etsy (août 2025) recommande des titres lisibles, "comme si un humain l'avait écrit". Le keyword stuffing ne crée pas de pénalité directe mais réduit le CTR → le listing quality score baisse → le rang baisse. L'effet est réel même sans pénalité.

**Règle 4 — 140 chars = 2-3 expressions complémentaires**
Structure recommandée :
```
[Mot-clé primaire], [Variante/matière/taille], [Contexte d'usage ou occasion]
```
Pas de séparateurs obligatoires. La virgule est la plus lisible et la plus répandue. Etsy est agnostique aux séparateurs (virgule / pipe / espace = même résultat d'indexation).

**Règle 5 — Mots d'occasion et destinataire → pas dans le titre, dans les tags**
"Gift for her", "Birthday present", "Mothers Day" → tags et attributs (Etsy août 2025). Exception : si l'occasion EST le produit (ex : "Christmas ornament"), la garder dans le titre.

**À ne pas faire :**
- Répéter le même mot-clé plusieurs fois dans le titre ("cotton cotton bath cotton")
- Mettre le nom de la boutique dans le titre
- Commencer par un adjectif subjectif ("Beautiful", "Stunning", "Unique")
- Dépasser 15 mots (recommandation officielle Etsy)

## 3. Tags — règles applicables à tout produit

Etsy donne 13 tags de 20 caractères max chacun. Ce sont des phrases, pas des mots isolés.

### Règles

**Règle 1 — 13/13 slots toujours remplis**
Chaque slot vide = une chance de matcher une requête acheteur en moins. Coût : zéro. Ne pas remplir est une erreur pure.

**Règle 2 — Phrases multi-mots uniquement**
"handmade soy candle" > "candle". Etsy accorde un bonus de ranking sur les matches exacts phrase-à-phrase. Les tags mono-mots ne bénéficient pas de ce bonus.
Maximum 20 caractères par tag (espaces compris).

**Règle 3 — Tag #1 = répétition du mot-clé primaire du titre**
Le mot-clé le plus important doit apparaître à la fois dans le titre ET dans un tag. Signal de pertinence renforcé. Pour les 12 autres : zéro répétition avec le titre ou les autres tags. Couvre des synonymes, des variantes, des contextes d'usage différents.

**Règle 4 — Ne pas répéter les attributs dans les tags**
Les attributs (couleur, matière, style) sont déjà indexés comme des tags automatiquement par Etsy. Si tu mets "cotton" en attribut matière, ne pas l'ajouter en tag — slot perdu.

**Règle 5 — Couvrir toutes les dimensions de recherche**
Pour chaque listing, vise à couvrir :
- Le produit lui-même (1-2 tags)
- La matière / fabrication (1 tag)
- L'usage / la pièce / le contexte (1-2 tags)
- L'occasion / le destinataire (2-3 tags)
- La couleur ou le style (1-2 tags)
- Les synonymes que les acheteurs utilisent réellement (2-3 tags)

### Checklist tags (appliquer avant de valider)
- [ ] 13/13 remplis
- [ ] Aucun tag mono-mot
- [ ] Aucun tag qui répète exactement le titre ou un autre tag
- [ ] Aucun tag qui répète un attribut déjà rempli
- [ ] Au moins 2 tags à intention cadeau
- [ ] Au moins 1 tag saisonnier si pertinent

## 4. Attributs — non négociables

Les attributs sont scannés au même niveau que les tags dans la phase de query matching. Les buyers qui filtrent par couleur / matière / style sont des acheteurs à haute intention. Un attribut manquant = invisible à cette audience.

**Remplir systématiquement :**
- Couleur principale + couleur secondaire
- Matière / material
- Style (rustic, modern, minimalist, bohemian, etc.)
- Occasion (quand disponible)
- Pour home décor : Room (bathroom, bedroom, living room)
- Pour mode/bijoux : occasion de port, métal/pierre

**Ne pas mettre dans les tags ce qui est déjà dans les attributs.**

## 5. Description — structure optimisée SEO + conversion

### Ce qu'Etsy indexe
Les descriptions sont lues pour la pertinence (phase 2 du ranking, pas la phase 1). Poids inférieur aux titres + tags + attributs. Mais Etsy confirme qu'elles comptent pour la pertinence et l'IA de recherche les lit.

Les 160 premiers caractères = meta description pour Google Shopping (trafic externe). Critiques pour le SEO externe.

### Structure recommandée (applicable à tout produit)

```
[Ligne d'accroche courte — ton de la boutique, pas un slogan IA]

[Paragraphe produit : ce que c'est, matière, format, usage principal]

POURQUOI [CE PRODUIT]
- [Bénéfice 1 — issu du review mining, power word réel]
- [Bénéfice 2]
- [Bénéfice 3 — contre une objection fréquente]
- [Bénéfice 4]
- [Bénéfice 5]

SPECS
- Matière :
- Dimensions / format :
- Contenu du set (si applicable) :
- Entretien / utilisation :

PARFAIT POUR
[1-2 phrases sur le destinataire et le contexte d'usage : cadeau, usage quotidien, décoration, etc.]

FAQ
Q: [Objection #1 identifiée en review mining]
A: [Réponse directe avec preuve sociale si dispo]

Q: [Objection #2]
A: [Réponse]

[CTA final — 1 phrase, ton de la boutique]
```

### Règles de rédaction
1. Premier mot-clé primaire dans la première phrase (avant le 160e caractère).
2. Power words issus du review mining des avis acheteurs réels — jamais inventés.
3. Objections de la section 1-2 étoiles contrées dans les bullets et la FAQ.
4. Ton cohérent avec la Shop Identity Card — ne pas changer de registre en cours de description.
5. Pas d'adjectifs creux ("magnifique", "époustouflant", "unique"). Les avis acheteurs réels sont plus convaincants.

## 6. Recherche de mots-clés — processus générique

À lancer pour chaque nouveau produit, avant de rédiger le titre et les tags.

### Étape 1 — Trouver le mot-clé ancre
Cherche le terme le plus direct pour ce produit avec ces critères :
- Volume de recherche significatif (pas le plus élevé absolument — le plus élevé = concurrence max)
- Difficulté moyenne (sweet spot entre trafic et accessibilité)
- Intention d'achat claire (pas informationnelle)

Outils par ordre de fiabilité : RankHero (données Etsy directes) → Marmalead → eRank → Google Keyword Planner (volume Google, à transposer avec prudence).

### Étape 2 — Trouver les synonymes
Même intention, phrasing différent. Les acheteurs ne cherchent pas tous de la même façon. "bath towel set" et "bathroom towel set" ont le même volume — mais le second a moins de concurrence parce que les vendeurs n'ont pas remarqué.

### Étape 3 — Long-tail (3+ mots)
Ajoute un qualificatif : matière, couleur, occasion, nombre, usage. "Set of 3 cotton bath towels" cible un acheteur plus précis qui convertit mieux.

### Étape 4 — Mots saisonniers
Identifie les pics saisonniers pour la niche (voir `references/seasonality.md`). Ajoute 2-3 tags saisonniers qui peuvent être rotés sans changer le listing entier.

### Étape 5 — Identifier le gap vendeurs/acheteurs
Ce que les vendeurs sur-taguent (saturé, difficulté haute) ≠ ce que les acheteurs cherchent vraiment. Le gap = ta cible. Commande une recherche Gauthier (voir `references/gauthier-bridge.md` - mandat Psychographic) pour récupérer le vocabulaire acheteur réel.

### Output attendu
```
MOT-CLÉ ANCRE : [terme] — volume [X]/mois, difficulté [Y/100]
SYNONYMES : [terme 1], [terme 2]
LONG-TAIL : [phrase 1], [phrase 2], [phrase 3]
SAISONNIERS : [terme 1] (pic [mois]), [terme 2] (pic [mois])
MOTS À ÉVITER : [terme saturé 1], [terme creux 2]
```

## 7. Checklist SEO finale avant publication

Valider chaque point avant de poster ou de créer le brouillon Etsy.

### Titre
- [ ] Mot-clé primaire dans les 40 premiers caractères
- [ ] Langage naturel, lisible à voix haute
- [ ] Maximum 15 mots
- [ ] Pas d'adjectif subjectif en ouverture
- [ ] Pas de répétition du même mot-clé

### Tags
- [ ] 13/13 slots remplis
- [ ] Tous des phrases multi-mots
- [ ] Mot-clé primaire du titre répété dans 1 tag
- [ ] Zéro doublon avec les attributs
- [ ] Couvre : produit, matière, usage, occasion, couleur/style, synonymes

### Attributs
- [ ] Couleur primaire + secondaire remplis
- [ ] Matière remplie
- [ ] Style rempli
- [ ] Occasion remplie si le champ existe dans la catégorie
- [ ] Room rempli pour home décor

### Description
- [ ] Mot-clé primaire dans les 160 premiers caractères
- [ ] Power words issus d'avis réels (pas inventés)
- [ ] Au moins 2 objections contrées
- [ ] FAQ avec les vraies questions acheteurs
- [ ] Ton cohérent avec Shop Identity Card

### Images (impact SEO indirect via conversion)
- [ ] 6 images minimum, 6 angles différents
- [ ] Thumbnail (image principale) : produit occupe 75%+ du cadre, fond épuré
- [ ] Pas deux images avec le même angle de caméra
- [ ] Qualité suffisante (pas de pixelisation visible sur mobile)

### Livraison (impact SEO direct)
- [ ] Livraison US < 6$ ou gratuite (sinon malus de visibilité en US)
- [ ] Profil de livraison configuré dans Etsy (obligatoire pour les listings)

## 8. Erreurs SEO les plus fréquentes

| Erreur | Pourquoi ça nuit | Correction |
|--------|-----------------|------------|
| Tags mono-mots ("towel", "gift") | Pas de bonus exact-match, volume trop large | Remplacer par phrases 3-4 mots |
| Répéter les attributs dans les tags | Slots gaspillés | Utiliser ces slots pour des synonymes |
| Titre qui commence par un adjectif | CTR plus faible, Etsy le déconseille officiellement | Commencer par le nom du produit |
| Tags qui copient le titre mot pour mot | Slots gaspillés | Couvrir des angles différents |
| Laisser des tags vides | Reach gratuit perdu | Toujours 13/13 |
| Occasion dans le titre (hors cas évident) | Dilue le signal produit, Etsy le déconseille | Occasion → tags + attributs |
| Description vide ou de 3 lignes | Signal de pertinence faible, Google meta pauvre | Structure complète obligatoire |
| Attributs non remplis | Invisible aux acheteurs qui filtrent | Tous les attributs disponibles = remplis |
| Photos génériques / perspectives identiques | CTR faible → Listing Quality Score bas → rang bas | 6 angles différents obligatoires |
| Prix trop élevé vs concurrence sans justification | Conversion faible → ranking dégradé | Vérifier le prix marché dans competitor analysis |
